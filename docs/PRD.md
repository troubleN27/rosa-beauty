# PRD — Telegram-бот записи и админ-панель для салона красоты «Rosa Beauty»

## 1. Цель продукта

Система онлайн-записи для салона красоты (парикмахерские услуги, ногтевой сервис, брови и ресницы, макияж, уход за лицом), которая:
- позволяет клиенту записаться к мастеру за 1–2 минуты прямо в Telegram, без звонков и переписки;
- исключает двойные записи и ошибки администратора;
- напоминает клиентам о визите и снижает количество неявок;
- даёт владельцу салона удобную веб-панель для управления записями, мастерами, услугами и расписанием.

Состав продукта:
1. **Telegram-бот** — для клиентов.
2. **Веб-админка** — для владельца и администратора салона.
3. **Уведомления в Telegram** — для администратора (новые записи, отмены).

## 2. Пользователи

| Роль | Что делает | Что важно |
|---|---|---|
| Клиент | Записывается, смотрит и отменяет свои записи, оставляет отзыв | Быстро, понятно, без лишних шагов |
| Администратор / владелец | Управляет записями, мастерами, услугами, расписанием, смотрит статистику | Всё видно на одном экране, ничего не теряется |

Мастера в этой версии в систему не входят — их расписанием управляет администратор.

## 3. Языки

- Бот: русский и английский. Язык выбирается при первом запуске и меняется в меню.
- Админка: только русский.
- Названия и описания услуг, имена мастеров хранятся на двух языках.

## 4. Telegram-бот (клиент)

### 4.1 Первый запуск
- `/start` → приветствие салона → выбор языка (RU / EN).
- Главное меню (кнопки под полем ввода, клиент может свернуть их значком клавиатуры):
  - 🌹 Записаться
  - 🗓️ Мои записи
  - 💰 Услуги и цены
  - 👩‍🎨 Мастера
  - 📍 Контакты
  - 🌐 Язык
- Команды бота (список в меню Telegram, RU / EN): `/menu` — вернуть главное меню, `/book`, `/my`, `/services`, `/masters`, `/contacts`, `/language` — открыть соответствующий раздел.
- В каждом разделе, открытом сообщением с inline-кнопками, есть «✖️ Закрыть» (сообщение убирается из чата); во вложенных экранах — ещё и «⬅️ Назад».

### 4.2 Запись (главный сценарий)
1. Выбор категории услуг: Стрижки и укладки, Окрашивание, Маникюр и педикюр, Брови и ресницы, Макияж, Уход за лицом.
2. Выбор услуги — название, длительность, цена.
3. Выбор мастера: список мастеров, которые выполняют эту услугу, + вариант «Любой мастер».
4. Выбор даты: календарь на ближайшие 14 дней; дни без свободного времени неактивны.
5. Выбор времени: только реально свободные слоты (с учётом графика мастера, длительности услуги, перерывов, выходных и уже существующих записей).
6. Контакты: имя и телефон. Телефон — через кнопку «Поделиться номером»; при повторных записях данные подставляются автоматически.
7. Подтверждение: сводка (услуга, мастер, дата, время, цена, адрес) → кнопки «Подтвердить» / «Изменить» / «Отмена».
8. Успех: сообщение с деталями записи и адресом салона.

Требования к сценарию:
- На каждом шаге есть кнопка «Назад».
- Если выбрано «Любой мастер», показываются все свободные слоты всех подходящих мастеров; при выборе времени назначается свободный мастер.
- Если пока клиент выбирал, слот заняли — бот сообщает об этом и предлагает выбрать другое время.
- Нельзя записаться на прошедшее время и позже, чем на 14 дней вперёд.

### 4.3 Мои записи
- Список будущих записей клиента.
- Для каждой: «Отменить» и «Перенести».
- Отмена и перенос возможны не позднее чем за N часов до визита (N задаётся в настройках, по умолчанию 3). Если позже — бот просит связаться с салоном и показывает телефон.
- Перенос = выбор новой даты и времени у того же мастера на ту же услугу.

### 4.4 Информационные разделы
- **Услуги и цены** — по категориям, с длительностью и ценой.
- **Мастера** — фото, имя, специализация, стаж, кнопка «Записаться к мастеру».
- **Контакты** — адрес, телефон, часы работы, геолокация (точка на карте Telegram), ссылка на Instagram.

### 4.5 Напоминания и отзывы
- Напоминание за 24 часа и за 2 часа до визита с кнопками «Приду» / «Отменить» (отмена — по правилам 4.3).
- Через 2 часа после завершения визита (статус «Выполнена») — просьба оценить визит от 1 до 5 и, по желанию, оставить комментарий.

### 4.6 Уведомления администратору
- В Telegram-чат администратора приходят: новая запись, отмена, перенос, новый отзыв с оценкой ≤ 3.

## 5. Веб-админка

### 5.1 Вход
- Вход по email и паролю. Регистрации нет — аккаунты администраторов создаются вручную.

### 5.2 Главная (дашборд)
- Записи на сегодня по времени.
- Показатели за неделю: количество записей, выручка по выполненным записям, отмены, неявки, средняя оценка.

### 5.3 Расписание
- Вид «День» и «Неделя»: колонки по мастерам, записи блоками по времени.
- Клик по записи — карточка записи.

### 5.4 Записи
- Таблица с фильтрами: дата, мастер, статус, источник (бот / админка).
- Статусы: Подтверждена, Выполнена, Отменена, Неявка.
- Карточка записи: клиент, услуга, мастер, время, цена, комментарий, история изменения статуса.
- Действия: изменить статус, перенести, отменить. При отмене или переносе администратором клиент получает сообщение в бот.
- Создание записи вручную (для клиентов, которые позвонили или пришли сами) — с теми же проверками свободного времени.

### 5.5 Услуги
- Категории и услуги: название (RU/EN), описание (RU/EN), длительность, цена, активна/скрыта, порядок отображения.

### 5.6 Мастера
- Имя (RU/EN), фото, специализация (RU/EN), стаж, список услуг, которые мастер выполняет, активен/скрыт.
- График работы по дням недели (начало, конец, перерыв).
- Выходные и отпуска (даты, когда мастер не работает).

### 5.7 Клиенты
- Список клиентов из бота: имя, телефон, количество визитов, последний визит, отменённые записи и неявки.
- Карточка клиента с историей записей.

### 5.8 Отзывы
- Список отзывов с оценкой, комментарием, мастером и услугой; фильтр по оценке.

### 5.9 Настройки
- Название салона, адрес, телефон, часы работы, геолокация, Instagram.
- Часовой пояс салона.
- Шаг слотов (по умолчанию 15 минут).
- Минимальное время до записи (по умолчанию 1 час).
- Срок отмены/переноса клиентом (по умолчанию 3 часа).
- Включение/выключение напоминаний и запросов отзывов.

## 7. Нефункциональные требования

- **Надёжность:** бот не теряет записи при перезапуске; напоминания отправляются, даже если бот был перезапущен.
- **Время:** все даты хранятся в UTC, показываются в часовом поясе салона.
- **Скорость:** ответ бота на нажатие кнопки — до 1 секунды.
- **Безопасность:** админка доступна только после входа; секретные ключи только на сервере и в переменных окружения; данные клиентов не видны без авторизации.
- **Админка:** адаптивна (удобна на ноутбуке и планшете, базовые действия работают с телефона).
- **Тексты:** весь контент бота, админки, кода и README написан как для действующего салона — без пометок «демо», «пример», «тестовый проект» или «портфолио».
- **Тон бота:** тёплый, «салонный», без канцелярита. Сообщения оформлены в стиле сайта: заголовок с розой 🌹, пункты списков — простыми строками без маркеров; остальные эмодзи — только на кнопках. Описание услуг, «билет» визита, напоминания и отзывы показываются полностью, без сворачивания.

## 8. Вне рамок проекта (НЕ делаем)

- Онлайн-оплата и предоплата.
- Несколько филиалов.
- Личные кабинеты мастеров.
- Запись через сайт (только Telegram).
- SMS и email-уведомления.
- Программа лояльности, бонусы, промокоды.
- Массовые рассылки клиентам.
- Мобильное приложение.

## 9. Критерии готовности

- Клиент может пройти весь сценарий записи на обоих языках, запись появляется в админке.
- Двойная запись на одно время к одному мастеру невозможна — даже при одновременных запросах.
- Отмена, перенос, напоминания и отзывы работают по описанным правилам.
- Администратор получает уведомления в Telegram.
- Все разделы админки из пункта 5 работают; изменения услуг, мастеров и графиков сразу отражаются в боте.
- Автотесты расчёта свободного времени проходят.
- Сборка и линтеры проходят без ошибок.
- Есть README с описанием, стеком, инструкцией по запуску и деплою.
